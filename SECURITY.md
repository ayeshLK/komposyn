# Security Policy

## Supported versions

Only the latest released version receives security fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's
private vulnerability reporting if it is enabled for this repository. If it is
not available, contact the maintainers privately before disclosing the issue.

Include the affected version or commit, reproduction steps, impact, and any
suggested mitigation. Do not include credentials, provider transcripts,
prompts, responses, or other sensitive source content.

The token logger is local-first and should never require provider credentials
for ingestion or reporting.
